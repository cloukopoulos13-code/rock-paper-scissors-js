Rock, Paper, Scissors in JS

This project is designed to test my problem solving and basic JavaScript skills for the first time in the Odin Project.

When completed, it will be able to take an input from the user of Rock, Paper or Scissors, create a random choice for the computer, and pit the two against each other to see who wins. Lastly, I will include input handling so the user cannot enter anything except the three options, otherwise a message will display and they will have to choose again. There will also be a menu to play again, or exit.
